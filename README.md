# About

Crystals is a small mod avaliable for **Forge, Fabric and NeoForge** witch adds new crystals witch generates on top of ores like: Redstone, Lapis, Emerald and Diamond.

Each crystal drops the corresponding mineral (e.g. diamond crystals drops diamonds).

## 1.4.0 Update

In this update, new geodes based on minerals is added into the world. And on those you can find enriched ore blocks which you can grow your own crystals with dripstone and water.
